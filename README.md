# Forma — Visual Website Builder

An orange-accented visual website builder prototype built with Next.js, TypeScript, Tailwind CSS, and Lucide icons. Its UI takes inspiration from shadcn/ui's restrained zinc palette, subtle borders, and rounded controls.

## Getting started

```bash
npm install
npm run dev
```

## Editor features

- Three-panel workspace: element palette, responsive canvas, and properties inspector
- Orange primary color (`#EA580C`) with zinc neutral surfaces
- Lucide React iconography
- Add, select, edit, duplicate, delete, and reorder canvas elements
- Desktop, tablet, and mobile canvas widths
- Preview mode, undo/redo, and standalone HTML export

This branch is a frontend prototype. The Publish action exports a standalone HTML file; it does not deploy a website to a hosting provider.
